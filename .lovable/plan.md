# Plan: Remove the Lovable logo from social sharing previews

## Problem found
- The homepage currently points `og:image` / `twitter:image` to a portrait photo (`arm-laser.jpg`, 1125×1406), which is the wrong aspect ratio for social previews and may cause platforms to fall back to a default.
- The `/why-laser` route is generated by `scripts/postbuild-meta.mjs`. That script rewrites title/description/OG tags but does **not** carry over the `og:image` and `twitter:image` tags, so `/why-laser` has no social image at all. Lovable hosting is then injecting its own default preview — the Lovable logo you see when sharing.

## What we will do
1. **Create a branded 1200×630 social preview image**
   - Generate a premium, on-brand image using the Laser Location identity (dark editorial background, champagne-gold/dusty-blush accents, Playfair/Inter typography).
   - Include the offer headline, business name, and a treatment-related visual.
   - Save it as `public/og-image.jpg` so Vite copies it to `dist/` and it is served from the custom domain.

2. **Update `index.html` social tags**
   - Replace the current `og:image` and `twitter:image` URLs with the absolute domain URL: `https://offer.laserlocation.co.uk/og-image.jpg`.
   - Keep all existing titles, descriptions, canonical, Pixel, and Clarity code unchanged.

3. **Fix `scripts/postbuild-meta.mjs`**
   - Make the script preserve the base `og:image` and `twitter:image` tags when writing the `/why-laser` static HTML, so that route also serves the branded preview.
   - (If we later add route-specific images, we can extend the same logic; for now we will use the single branded image across all routes.)

4. **Verify**
   - Run a production build.
   - Inspect `dist/index.html` and `dist/why-laser/index.html` to confirm both contain the correct `og:image` / `twitter:image` tags.
   - Confirm `dist/og-image.jpg` exists and is 1200×630.

## Out of scope
- No changes to favicon (already correct).
- No changes to page design, copy, or routing.
- No backend/Supabase changes.

## Expected result
Sharing any page from `offer.laserlocation.co.uk` will show the Laser Location branded preview image instead of the Lovable logo.
